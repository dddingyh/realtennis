网球手柄

把手机当球拍：倾斜走位，挥拍击球

需要 HTTPS 才能使用传感器

浏览器只在安全上下文（HTTPS 页面）里开放陀螺仪 / 加速度计。当前地址不是 HTTPS，所以手机传感器无法使用。

  • 请通过部署在 GitHub Pages（https://…）的游戏页面扫码打开本页。
  • 局域网 http://192.168.x.x 地址无效（iOS 与 Android 均不开放传感器）。
  • 在电脑上调试可在地址后加 &sim=1 使用传感器模拟器。

1 / 3　你是哪只手持拍？

用来区分正手 / 反手的挥拍方向。以后可在设置里更改。

2 / 3　握拍姿势与中立校准

  1. 像握网球拍柄一样握住手机下端，手机顶端就是拍头。
  2. 拍头朝正前方并略微抬高（约 30°），屏幕即拍面（朝哪一面都行）。
  3. 保持这个姿势不动 2 秒 —— 这就是“站定不动”的中立位。

准备好后按下按钮，然后保持不动。

3 / 3　挥拍校准（可选）

每种击球挥 3 次，让手机学会你的动作。跳过也能玩（使用默认判定）。
